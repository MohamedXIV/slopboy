# Slopboy project instructions for Claude Code

**Mandatory project orientation:** Read [AGENTS.md](AGENTS.md), [ROADMAP.md](ROADMAP.md), and [docs/product/long-term-vision.md](docs/product/long-term-vision.md) before substantial implementation or architecture changes, then the relevant current ADR and GitHub Issue.

Do not treat deferred gameplay economy, multiplayer, community or 3D features as MVP deliverables. Preserve the documented compatibility/trust contracts without speculative implementation. For any AI-generated Slopboy cartridge, use an approved versioned framework template and the shared host interface; no standalone HTML/CSS/JS app submission.
